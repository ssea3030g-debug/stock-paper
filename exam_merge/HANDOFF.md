## 확정된 합본 형식(사용자 요구)
- A4. 머리글·바닥글·지문 제목은 변형본 그대로 쓴다. 출처 줄과 "학력평가 원문 보기", 표시어 박스는 지운다.
- 지문은 원본 시험지에서 이미지로 잘라 넣고 발문("[21~25] 다음 글을…")은 뺀다. 원본에서 나뉜 상자는 이음매 줄 없이 이어 붙인다.
- 지문은 왼쪽 단부터 흘려 넣는다. 넘치면 오른쪽 단, 그다음 쪽으로 넘기고, 단 경계에서는 빈 줄을 따라 자른다.
- 지문이 끝난 바로 아래 자리부터 문항을 차례로 넣는다(문항 사이 간격 48pt).
- 정답은 각 지문 마지막 쪽의 오른쪽 아래, "문제편" 밑에 가로로 적고 180° 돌려 거꾸로 둔다(`answers.json`).
- 표시어 (a)·(b)는 지문 속 해당 구절에 밑줄을 긋고 왼쪽 여백에 (a)를 적는다(`marks.json`).

## 변형 문항 작업 현황
- 학교 기출(보인고 2025-2 독서 중간·기말)을 분석해 `출제규칙_초안.md`로 정리했다. 7절에 실제로 적용한 결정이 있다.
- **29개 지문 전부** 새 문항으로 바꿨다(`custom_questions/<지문>/q*.json`, 지문당 6~7문항, 선택형 + 단답형 1).
- 전체 합본: `새문항_전체.pdf`(67쪽, 정답은 각 지문 마지막 쪽 아래에 거꾸로).
- 다음: 사용자 검토 의견을 받아 문항을 고친다. 고칠 때는 json을 바꾸고 `render_custom.py` → `build.py` 순서로 다시 만든다.

### 출제 원칙(사용자가 지적한 것)
- **문항은 지문 안의 내용만으로 풀 수 있어야 한다.** 지문에 없는 수치, 단위, 가상 사례로 계산 문제를 만들지 않는다. 처음에 kWh 계산 문제를 냈다가 지적받았다.
- 원본 시험지 문항은 참고만 하고 그대로 베끼지 않는다.
- 문항 수준은 높게, 내신 형식으로 낸다.

### 새 문항 넣는 방법
- `custom_questions/<지문>/q<번호>.json`에 문항을 적는다. 키는 다음과 같다.
  - `stem`: 발문
  - `bogi_text`: <보기> 본문(선택)
  - `bogi_lines`: ㄱㄴㄷㄹ 항목(선택)
  - `table`: 보기 속 표(선택)
  - `choices`: 선지
  - `short`: 단답형이면 true
  - `answer`: 정답
- `python3 exam_merge/render_custom.py`로 문항 그림(PNG)을 만든다. 그다음 `build.py`를 돌리면 그 지문의 문항 전체가 새 문항으로 바뀌고, 정답도 json의 `answer`를 쓴다.
- 글꼴은 `fonts/`의 나눔명조 부분 글꼴(변형본 PDF에서 꺼낸 것)을 먼저 쓰고, 없는 글자는 같은 나눔명조 전체 글꼴(`NanumMyeongjo-*.ttf`, google/fonts에서 git으로 받음, SIL OFL)로 찍는다.
  - 나눔명조에도 없는 ⓐ~ⓔ, Ⅰ~Ⅲ, ㎐, ㎛, 한자는 WenQuanYi로 찍힌다. 한자는 문항에 쓰지 않았다.
- 발문의 "않은 것/틀린 것/다른 하나" 등 부정어는 자동으로 밑줄을 긋는다. 선지가 14자 이하(ㄱ, ㄴ 조합 등)면 한 줄에 셋씩 배치한다.
- render_custom.py의 임시 HTML 이름이 지문마다 겹치던 버그(모든 지문 문항이 같은 그림이 됨)를 고쳤다.

## 남은 확인 사항
- 새 문항 정답은 각 json의 `answer`다. 지문 그림(과학 03, 과학 05 등)을 함께 보는 문항은 사람이 한 번 더 확인하면 좋다.
- (이전 변형본 문항용) `answers.json`의 정답은 직접 풀어서 넣은 것이다. 그래프나 그림을 보고 푸는 문항은 사람이 확인해야 한다(과학 01-2, 과학 03-2, 사회 05-3, 기술 03-2, 기술 05-2, 인문 04-4).

## 고난도 (가)(나)(다) 세트
- 기출의 고난도 방식(지문 3개를 (가)(나)(다)로 묶고, 선지마다 정보를 많이 넣어 인과 관계를 뒤집는 오답)을 따라 3세트를 만들었다.
  - 고난도01: 사회01 과징금 + 사회07 부관 + 사회08 신뢰 보호
  - 고난도02: 기술01 건조기 + 기술02 열펌프 + 기술03 습도 센서
  - 고난도03: 과학03 청각 + 과학04 후각 + 과학01 약물
- 니체(인문08)와 페로브스카이트(기술04)는 사용자 요청으로 고난도 세트에서 뺐다.
- 묶음 정의는 `combo_sets.json`, 문항은 `custom_questions/고난도0N/`, 조판은 `python3 exam_merge/build_combo.py --out 고난도_가나다_3세트.pdf`.
- 세트당 7문항: 세 지문 관계 → (가)·(나)·(다) 각각의 인과 판단 → ㄱㄴㄷㄹ 종합 → 세 지문을 함께 적용하는 <보기>(3.8점) → 단답형(3점).

# 출제 규칙 초안 (보인고 2025-2 중간·기말 독서 기출 분석)

대상: 중간고사(선택형 32) · 기말고사(선택형 32 + 단답형 3). 2학년 독서(비문학).

## 1. 구성
- 지문 세트: 중간 10세트, 기말 9세트. 세트당 2~5문항(대부분 3). 지문이 길면(과학 복합지문) 5~8문항.
- 지문 형태: 단일 지문, 또는 (가)(나)(다) 복수 지문(관점 비교·통합). 지문 속 밑줄 ㉠㉡, [A]·[B] 구간 표시, 그림·그래프 삽입.
- 기말은 3개 세트(1-3, 9-11, 17-19)에 단답형이 1문항씩 붙는다.
- 배점은 발문 끝에 `[3.1점]` 식으로 표기. 2.5~3.6점, 어려운 문항일수록 높고 보기 계산·그림 해석형이 3.4~3.6점.

## 2. 문항 유형과 비율(대략)
| 유형 | 비율 | 발문 표현 예 |
|---|---|---|
| <보기> 적용·반응·사례 판단 | 중간 약 40% / 기말 약 25% (+단답 3개 전부) | "윗글을 바탕으로 <보기>를 이해한 내용으로 가장 적절한 것은?", "(가)~(다)를 바탕으로 <보기>에 대해 보인 반응으로 적절하지 않은 것은?" |
| 내용 일치·이해(세부 정보, 추론) | 약 35% | "윗글에 대한 이해로 적절하지 않은 것은?", "윗글을 읽고 추론한 내용으로…" |
| 서술·전개 방식 | 약 8% (세트당 1) | "(가)와 (나)에 대한 설명으로…", "[A]의 서술 특징으로…", "윗글의 전개 방식으로…" |
| 밑줄 ㉠~㉢ 비교·이유 | 약 8% | "㉠의 이유로…", "㉠과 ㉡을 비교한 설명으로…", "㉠~㉢의 공통점으로…" |
| 문맥상 바꿔 쓰기·의미 | 기말 3문항 | "문맥상 ⓐ~ⓔ와 바꿔 쓰기에 적절하지 않은 것은?" |
| 그림·그래프·표 해석 | 과학·경제 지문에서 1~3 | "그래프를 이해한 내용으로…" |
| 관점 비교·비판 | (가)(나) 세트에 1 | "(다)의 관점에서 볼 때 (가)의 입장에 대한 비판적 시각으로…" |
| 탐구 질문 | 세트에 0~1 | "추가로 탐구하고자 하는 내용으로", "답을 찾을 수 있는 질문으로" |
- 부정형("적절하지 않은 것은?")은 약 35~40%. 부정어는 밑줄로 강조.
- 정답 번호는 ①~⑤에 고르게 분포.

## 3. 발문
- 형식: "윗글(을/에 대한/을 바탕으로) …한 것은?" / "(가)~(다)를 바탕으로 <보기>를…" + `[점수]`.
- 지문 지칭: 단일 지문은 "윗글", 복수 지문은 "(가)", "(나)", "[A]".
- 길이: 한 줄 안팎. 조건이 필요하면 "(단, <조건>을 참고할 것.)".

## 4. <보기>
- 박스에 `<보 기>` 제목. 길이 3~6줄.
- 내용: 지문 원리를 적용할 **새 사례·자료**(가상 인물의 상황, 실험, 작품 평가, 날짜·금액을 정한 법률 사례 등). 지문 내용을 반복하지 않는다.
- 변형: ㄱㄴㄷㄹ 진술 판단형(조합 선지 ①ㄱ,ㄴ ②ㄴ,ㄷ…), 표·그림·그래프 포함형, 빈칸(㉮)에 들어갈 말 추론형.
- 선지는 <보기> 속 사례를 지문 개념으로 해석하는 문장: "(지문 개념)에 따르면 (보기 사례)는 (해석)이므로 …했겠군 / 볼 수 있다".
- 어미: "~겠군", "~볼 수 있다", "~것이다".

## 4-1. 선지
- ①~⑤, 각 1~3줄. 근거를 붙이는 문장("~하므로 ~이다", "~때문에")이 많다.
- 오답 만드는 방식:
  1. 지문의 주체·대상 바꾸기(㉠↔㉡, 가↔나, 인물 입장 교차)
  2. 인과 방향 뒤집기, 조건 누락
  3. 범위 과장("모두", "항상", "오직", "전혀")
  4. <보기> 사례에 지문 원리를 잘못 대응
  5. 지문에 언급되지 않은 내용 추가(지문 밖 추론)
- 정답 선지도 지문 문장을 그대로 쓰지 않고 다른 표현으로 풀어 쓴다.

## 5. 단답형(기말)
- 유형: (1) 사례의 유형을 순서대로 쓰기(㉠:, ㉡:) (2) 빈칸에 들어갈 말을 지문에서 찾아 쓰기(조건: "㉠: 2음절, ㉡: 2어절", "지문 용어", "기호 명시") (3) 진술 5개 중 옳은 학생 **이름만 모두** 쓰기(부분점수 없음).
- 배점 2점(칸당 1점).

## 6. 표시·편집
- 머리글 `OOOO학년도 제 2학기 중간고사 2학년 독서과 문제지 n/12`, 반·번호·이름 칸.
- 지문 상자(테두리), 지문 속 밑줄 ㉠~ⓔ, 각주(*)는 별표로 지문 끝에.
- 문항 번호는 "1. " 굵게, 선지 ①~⑤ 단 정렬.

## 7. 29개 지문 변형 문항에 적용한 결정(사용자가 "진행"만 지시해 기본값으로 정함, 바꾸려면 알려 줄 것)
1. **<보기> 속 수치·날짜**: 기출처럼 <보기>가 필요한 사실을 모두 주고 지문의 원리·수치(예: 생체이용률, ±5%, 신청 기한 10일 전)만으로 풀리는 경우에만 썼다. 지문에 없는 단위·공식으로 계산하는 문항은 내지 않았다.
2. **지문당 6~7문항**: 선택형 5(지문에 ⓐ~ⓔ가 있으면 문맥 어휘 1문항을 더해 6) + 단답형 1.
   - 세트 구성: 서술 방식/(가)(나) 설명 → 내용 일치(부정형) → ㉠㉡ 비교·이유 → <보기> 사례 적용(최고 배점) → ㄱㄴㄷㄹ 고르기 → (문맥 어휘) → 단답형.
3. **단답형**: 지문마다 1개. 대부분 "지문에서 찾아 쓰기(음절·어절 조건)", 인문07·사회08은 "옳은 학생 이름 모두 쓰기".
4. **배점**: 발문 끝에 [2.6~3.6점], 단답형 [2점].
5. **그림 <보기>**: 쓰지 않았다. 표는 과학05, 기술05에만 썼다.
6. 정답 위치: ①28 ②27 ③36 ④30 ⑤32(선택형 182개 중 단답 제외 153개).

# 파크골프 수첩

할머니가 휴대폰으로 쓰기 쉽게 만든 파크골프 앱입니다. 설치 없이 인터넷 주소로 열고, 홈 화면에 아이콘으로 추가해서 씁니다.
기록은 **그 휴대폰 안에만** 저장됩니다(서버·회원가입 없음).

## 화면 구성 (아래 5개 탭)

| 탭 | 하는 일 |
|---|---|
| 🏠 처음 | 인사, 다음 일정 D-day, 자주 가는 골프장 지금 상태, 큰 메뉴 8개 |
| 📝 성적 | 대회·연습 성적 기록 → 그날 날씨·골프장 특징과 합쳐 **잘한 점 / 보완할 점 / 연습 과제** 분석. 소리로 듣기, 카톡으로 보내기 |
| 💰 내기 | 이름·점당 금액 정하고 홀마다(또는 합계만) 타수 입력 → 자동 정산, **누가 누구에게 얼마** 정리 |
| ⛳ 골프장 | 이름 검색·내 주변 찾기 → 지금 날씨·미세먼지·시간별 예보·3일 예보와 **운영 예상**(휴장일·비·바람·폭염·침수) |
| 📅 일정 | 파크골프 일정만 따로 관리, **삼성 캘린더에 넣기**(.ics, 알림 포함), 구글 캘린더, 캘린더 파일에서 파크골프 일정만 가져오기 |

그 밖에: 나의 플레이 스타일 분석(그래프, 파3·4·5별, 날씨별, 잔디별, 대회 vs 연습), 준비물 체크리스트(날씨 맞춤), 몸풀기 체조(소리 안내), 글자 크기 3단계, 밝게/어둡게, 백업·복원.

### 어르신을 위한 설계
- 기본 글자 23px(설정에서 27px까지), 버튼 높이 60px 이상, 숫자는 키보드 대신 **－ ＋ 버튼**
- 용어를 쉬운 말로(OB → "공이 밖으로 나간 횟수"), 색만으로 뜻을 전하지 않고 글자를 함께 표시
- 지우기 전에는 항상 큰 확인창, 화면 아래 탭은 그림+글자

### 내기 계산 방식
- **타당**: 다 친 뒤 모든 사람끼리 타수 차이 × 점당 금액을 주고받음 (3명: 70·72·73타, 1,000원 → +5,000 / −1,000 / −4,000)
- **홀 이기기**: 홀마다 혼자 제일 적게 친 사람이 다른 사람에게 1점씩. 선택: 비기면 다음 홀로 이월
- **버디 보너스**(선택): 버디 1점, 홀인원 3점을 다른 사람 각자에게서 받음

### 운영 상황에 대해
골프장 운영 여부를 알려 주는 공개 API가 없어서, **날씨와 직접 넣은 휴장일·운영시간으로 짐작**합니다. 화면에도 "예상"이라고 쓰고 전화 버튼을 함께 둡니다.

### 삼성 캘린더 연결의 한계
웹 앱은 휴대폰 보안상 삼성 캘린더를 직접 읽거나 쓸 수 없습니다. 그래서
- 넣기: 표준 캘린더 파일(.ics)을 공유/다운로드 → 삼성 캘린더로 열어 저장 (하루 전·2시간 전 알림 포함)
- 가져오기: 캘린더에서 내보낸 .ics 파일을 고르면 "파크골프·골프·대회" 일정만 골라 가져옴

## 사용하는 서비스
키 없이도 모든 기능이 돌아갑니다.
- 날씨·과거 날씨: Open-Meteo / 미세먼지: Open-Meteo Air Quality
- 골프장 검색: OpenStreetMap Nominatim, 내 주변: Overpass API

**선택: 서버 연결** ([`parkgolf-server/`](../parkgolf-server/README.md), Cloudflare Workers 무료)
- 지금 날씨·시간별·3일 예보를 **기상청 단기예보**로 바꿈 (지난 비·해 뜨는 시간·자외선은 Open-Meteo 유지)
- **🤖 AI 코치**: 경기 화면과 ‘나의 분석’에 버튼이 생기고, Claude 가 기록·날씨·골프장 특징·지난 기록을 함께 보고 쉬운 말로 분석 (유료, 한 번에 대략 100원 안팎 예상)
- 설정 → 서버 연결에 주소와 비밀번호만 넣으면 됨. 서버가 꺼져 있으면 자동으로 기본 날씨·기본 분석으로 돌아감

## 올리기 (GitHub Pages)
1. 저장소 Settings → Pages → Source: **GitHub Actions**
2. `main` 에 `parkgolf/` 변경이 올라가면 `.github/workflows/parkgolf.yml` 이 자동 배포 (Actions 탭에서 수동 실행도 가능)
3. 주소: `https://<깃허브아이디>.github.io/stock-paper/`
4. 할머니 휴대폰에서 주소를 열고 → 삼성 인터넷 ☰ → "현재 페이지 추가" → "홈 화면"

> 한 저장소에는 Pages 사이트가 하나뿐이라 `daily.yml`(신문)로 Pages 배포를 하면 이 앱이 덮어써집니다. 신문은 지금 Claude 아티팩트로 발행 중이라 충돌하지 않습니다.

내 컴퓨터에서 보기: `cd parkgolf && python3 -m http.server 8000` → http://localhost:8000

## 파일
```
parkgolf/
  index.html            화면 틀, 아래 탭
  style.css             큰 글씨·고대비 디자인 (밝게/어둡게)
  app.js                화면과 저장(localStorage)
  analysis.js           성적 분석·내기 정산 계산 (Node 로 시험 가능)
  weather.js            날씨·미세먼지·골프장 검색·운영 예상
  sw.js, manifest.webmanifest, icon*  앱 설치·오프라인
  tests/calc.test.js    계산 테스트: node --test parkgolf/tests/calc.test.js
parkgolf-server/        (선택) 기상청 날씨·AI 코치 중계 서버
```
